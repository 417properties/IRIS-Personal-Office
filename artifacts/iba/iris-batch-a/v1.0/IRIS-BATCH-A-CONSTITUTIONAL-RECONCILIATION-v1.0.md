# 1. A1-A5 Constitutional Contract Set

## A1 — Epistemic State Contract

One algebra governs source evidence -> canonical state -> candidate/root representation -> classification -> coverage -> projection -> persistence -> reconstruction.

Material states are explicit:
`KNOWN(value,basis)`, `UNKNOWN(reason)`, `MISSING(required_ref)`, `UNAVAILABLE(source)`, `STALE(value,as_of,expiry)`, `CONFLICT(values,bases)`, `INVALID/REJECTED(reason)`, `INAPPLICABLE(basis)`.

Lifecycle (OPEN/SATISFIED/SUPERSEDED/ABANDONED etc.) is separate from epistemic state.

Rules:
- safe denial is not proof of negative fact;
- known absence != UNKNOWN != unavailable;
- every material admitted root has one auditable disposition: required, not-required-with-basis, unknown, conflict, privacy-excluded, terminal/audited, or HOLD;
- no silent root/item disappearance;
- coverage derives from the same item facts and cannot contradict item disposition;
- freshness is as-of qualified;
- optional representation fields cannot carry load-bearing semantics without explicit presence/domain rules.
