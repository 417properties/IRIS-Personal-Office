# 03 — Transition-Filtration Constitution

Core rule:
EVERY_MEANINGFUL_TRANSITION_ARROW_IS_A_GOVERNED_QUALIFICATION_BOUNDARY.

Canonical flow may include:
RAW_EVENT -> EVIDENCE -> CLAIM/REPRESENTATION -> CANDIDATE_DELTA -> VALIDATED_RESULT -> GOVERNED_STATE -> SUBSTRATE_CONTEXT -> COMPETENT_ACTION -> NEW_EVIDENCE/LEARNING_INPUT.

## Arrow contract

Every consequence-bearing arrow declares:
source identity/referent; authoritative base/as-of; A1 epistemic/coverage requirements; materiality predicate; A3 privacy/authority requirements; consumer; minimum sufficient information/representation; permitted dispositions; proof/provenance retained; invalidators/reactivation; retention/reconstructability; compression/translation loss; failure/HOLD semantics; resource entitlement where material.

Permitted dispositions are IRIS-native equivalents of:
PASS / REFINE / COMPRESS / REFERENCE / ROUTE / DEFER / SUPPRESS / HOLD / ESCALATE / REJECT / UNKNOWN / ARCHIVE_PROVENANCE.

## Mechanisms

Progressive filtration: spend cognition/resource only as consequence/uncertainty requires.
Proof-carrying transitions: receiving side can reconstruct why passage was earned.
Invalidator-driven wake: DECIDE -> SLEEP -> RELEVANT_INVALIDATOR -> REQUALIFY.
Reversible suppression: preserve why/against-which-Current/reactivation/expiry/reconstructability.
Filter self-economics: Personal BIRE measures filtration burden versus downstream reconstruction saved.
Compile-time filtration: validate schemas/vocabularies/static contracts before runtime where possible.
Federated/local filtration: qualify near the consequence boundary; do not create one giant filtration service.

## Cognition interaction

Filtration-conditioned cognition failure is distinct from intrinsic reasoning failure. Wrong base, stale Current, overcompression, lost uncertainty, authority laundering or incomplete retrieval can make a capable model reason from a defective world representation.
