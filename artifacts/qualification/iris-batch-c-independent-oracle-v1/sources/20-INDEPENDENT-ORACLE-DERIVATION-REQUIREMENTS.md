# 20 — Independent Oracle Derivation Requirements

Ordering:
BATCH_A_CONSTITUTIONAL_SEMANTICS -> INDEPENDENT_ORACLE_DERIVATION -> PROOF_SELECTION -> IMPLEMENTATION_CONFORMANCE -> INDEPENDENT_ACCEPTANCE.

Implementation != oracle derivation != independent acceptance.

## Admission boundary

Oracle worker receives:
- this Batch-A package and exact source manifest;
- sealed audit as falsification/traceability evidence;
- permitted founding/Blueprint/current source objects;
- preserved candidate-independent evaluation inputs where needed.

It must not receive repaired candidate outputs, score-derived configuration or implementation-authored expected results before freezing the governing oracle.

## Oracle products

1. A1 epistemic/domain truth tables including missing/unavailable/stale/conflict/invalid and destination conservation.
2. A2 identity/equivalence/occurrence/continuation truth tables.
3. A3 authority/privacy/capability eligibility mutation matrix.
4. A4 action/effect/retry/reconciliation/objective-lifecycle state machine oracle.
5. A5 repository/reconstruction/projection/workflow conformance oracle.
6. Executive Reasoning observable-product oracle without private chain-of-thought requirements.
7. Filtration/ICCP round-trip/loss/privacy/currentness oracle.
8. Functional Perception configuration/claim/transfer/freshness oracle.
9. IEF phase-floor + maturity-axis oracle.
10. Whole-stack scenario set spanning multiple contracts.

## Required counterexample classes

- unknown holder/owner/delegation with operational denial but epistemic UNKNOWN;
- terminal/inapplicable/private roots cannot silently disappear;
- same objective but distinct resolution; explicit equivalent resolution;
- denial-valued/future/expired/foreign authority;
- changed intent digest; duplicate call; crash/timeout before/after possible submission; revocation race;
- partial/wrong/unavailable effect;
- objective with multiple obligations and unsatisfied closure criteria;
- overlapping continuation generations;
- memory vs SQL reconstruction and malformed import;
- enum/schema/adaptor round-trip including NULL/missing keys;
- candidate qualification swap; missing tool/context/privacy/resource; expired qualification;
- qualified evidence without retention/disclosure permission;
- replay/reconstruction of one causal occurrence does not increase independent experience;
- projection identical content across independent runs preserves distinct run identity;
- expiry-only change invalidates as-of proof;
- Dense/Canonical/Wire unknown version/required extension/missing base/translation loss;
- leading-edge IEF capability cannot average away mandatory floor weakness.

## Proof claim schema

Every proof records:
claim/invariant; semantic source; dependency closure; proof method; PASS establishes; PASS does not establish; falsifier; independence class; implementation assumptions; evidence class; as-of/version.

No proof may use test count, field presence, helper PASS or local fixture PASS as a substitute for caller/whole-stack invariant proof.

## Acceptance

Oracle freeze must precede use as score/acceptance ground truth. If semantics are underdetermined, return the exact constitutional gap; do not choose the behavior most favorable to implementation.
