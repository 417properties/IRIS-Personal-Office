## Distillation

What is deliberately reduced:
- duplicated UNKNOWN predicates -> A1;
- multiple identity/equivalence rules -> A2;
- scattered authority checks -> A3;
- ad hoc effect/retry paths -> A4;
- memory/SQL/recovery definitions -> A5;
- competing capability truth stores -> Functional Perception + CapabilityQualification;
- ad hoc communication meanings -> ICCP Canonical with Dense/Wire as representations;
- test-authored semantics -> Batch-C oracle.

What is NOT required as a new service:
A1-A5 semantic contracts; filtration; Executive Reasoning constitution; maturity axes; temporal semantics; proof semantics. They can be libraries/types/validators/architectural rules.

Derived projections (Functional Perception, N3 state, attention views, Dense messages) are rebuildable and zero-authority. They do not create second Currents.

## Overbuilding controls

1. Shared semantic kernel before new services.
2. Prefer existing external standards for transport/interoperability.
3. Deterministic/local qualification before model calls.
4. Event/delta-driven sensing rather than continuous AI surveillance.
5. Eligibility before BIRE optimization.
6. Deferred scopes remain seams, not deployments.
7. Every new persistent representation must prove it is authoritative canonical state or derived/rebuildable; no third category by convenience.
8. Every new mechanism must identify the unique guarantee it protects and the burden it removes.

## North-Star check

The architecture reduces Aaron's expected courier/reconstruction/interruption burden by making handoffs, state, proof and continuation machine-addressable, while keeping consequential authority/privacy/reconciliation explicit.

It therefore preserves the Personal Office end state without treating “more automation” as the goal.
