# 05 — IRIS Personal Nervous System

The nervous system is observation/circulation/substrate-state physiology. It is not IRIS Current, authority, continuity or executive judgment.

## N1 Sensory / Observation

Observes qualified worker/tool/device/provider/runtime/communication facts: health, latency, failure/retry/recovery, resource use, capability changes, obligation/wait/wake, context/projection failure, verification signals, mode/provider switch.

N1 emits observations/deltas; it does not diagnose as truth or remediate by itself.

## N2 Causal Event / Circulation

Event envelope carries occurrence/event identity, representation/message identity, source/destination, ordering, parent/derived/responds-to, base Current/version, A3 privacy/authority references, acknowledgement/expiry, dedup/idempotency, provenance and required return/evidence destination.

ICCP Wire-compatible transport plus Dense semantics is the preferred physiology where appropriate. Exactly-once is never assumed.

## N3 Substrate / Capability State

Represents identity/role/sponsor/purpose, Functional Perception claims, qualification state, authority/privacy envelope, tool/credential boundary, lifecycle/expiry/revocation, health/availability, cost/metabolic profile, current work/obligations, return destination and recovery/continuation state.

N3 is derived/rebuildable; it is not a second Current.

## N4 Executive Orchestration / Control

Consumes A1/A5 state + N3 + Personal BIRE + A3 to instantiate, route, project context, delegate, pause, resume, revoke, replace, escalate, reconcile or retire substrates.

## Non-collapse

OBSERVATION != CONTROL.
TELEMETRY != CURRENT.
HEALTH_SIGNAL != DIAGNOSIS.
CAPABILITY_STATE != AUTHORITY.
TRANSPORT_PERSISTENCE != IRIS_CONTINUITY.
WORKER_PERSISTENCE != IRIS_CONTINUITY.
NERVOUS_SYSTEM != IRIS_EXECUTIVE_JUDGMENT.

BIG/Navigator can be queried/exchanged through bounded interfaces but never becomes IRIS Current/memory/authority.
